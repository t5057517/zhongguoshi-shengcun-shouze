# 中国式生存守则

已附带 Godot 4.7.2。双击 `启动游戏.cmd` 游玩；双击 `打开编辑器.cmd` 开发（会多出一个日志窗口，编辑器开着时别关它）。

- `GodotPC/`：游戏工程（竖屏，核心区 375x600，对应《关卡策划案》里的坐标）
- `案子/`：企划书与关卡策划案

## 工程结构（新版都在 `GodotPC/game/`）

| 文件 | 作用 |
|---|---|
| `game/Main.tscn` + `game.gd` | 主流程：标题 → 4 关 → 黑屏 0.5 秒 → 关卡标题卡 → 报告。**关卡顺序、结果文案**在 `game.gd` 顶部的 `LEVELS` / `RESULTS` |
| `game/level_base.gd` | 所有关卡的基类：画图工具（圆角框、气泡、伪二维码、文字）、输入、延时 |
| `game/screens.gd` | 标题、标题卡、生存报告、“请竖屏游玩”遮罩 |
| `game/sfx.gd` | 音效（程序合成，自动加载为 `Sfx`）。想换真实音效见文件开头注释 |
| `game/levels/L1_Haircut` | 第一关 只剪一次 |
| `game/levels/L2_CloseAd` | 第二关 我只是想关掉它 |
| `game/levels/L3_Captcha` | 第三关 验证码 |
| `game/levels/L4_Unsubscribe` | 第四关 回T退订 |

## 怎么调参数（不用改代码）

在编辑器里打开 `game/levels/` 下对应的 `.tscn`，点根节点，右侧检查器（Inspector）里就是这一关的参数，例如：

- 第一关：码的位置大小、手机初始位置、遮挡 1.5 秒 / 露出 0.7 秒、Tony 台词
- 第二关：跳过倒计时、滑动阈值、购物页停留时间、误触几次算“已被转化”
- 第三关：横幅间隔、验证码停留 2 秒、每次提速 20%、最多未命中次数
- 第四关：回复间隔 0.4 秒、等待 5 秒判定、判定后停留 1.5 秒

改完 `Ctrl+S` 保存，`F5` 运行。

## 开发快捷键

Esc 回标题 · R 重开本关 · 标题画面按 1~4 直接进关

## 其他

- 每关结果写入 `user://results.json`（result_id），控制台也会打印 `[结果] Lx result_id=...`
- 画面全部用代码绘制，没有图片素材；字体用系统自带中文字体。**导出网页版前需要放一个开源中文字体**（如思源黑体）到工程里替换 `game/fonts/`。
- `scenes/`、`scripts/` 是旧版横屏灰盒，已不再使用，确认不需要可以删除。
