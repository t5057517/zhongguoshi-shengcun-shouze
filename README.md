# 中国式生存守则

黑色幽默情景小游戏 H5 原型。以中国日常人情、客套与隐性规则为题材，竖屏 375×600，单页内切换关卡。

## 玩法

看懂场面 → 简单操作 → 现场反应 → 下一关。每关只使用一种主要操作。

## 关卡（当前 4 关，规划 99 关）

1. 只剪一次 — 拖动手机扫码付款
2. 我只是想关掉它 — 关闭开屏广告并卸载 App
3. 验证码 — 从横幅广告中找出验证码
4. 回T退订 — 发短信退订

## 运行

直接用浏览器打开 `game/index.html`，或本地起服务：

```bash
cd game && python -m http.server 8123
```

然后访问 http://localhost:8123

## 目录

- `game/` — H5 游戏源码（index.html + main.js 引擎 + level1~4.js 关卡）
- `案子/` — 企划书与关卡策划案（.docx）
